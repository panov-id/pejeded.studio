# PEJEDED STUDIO: как начать

Этот репозиторий — сам проект: задание на разработку (`docs/spec/`), эталон картинки (`docs/prototype/`), правила для Claude Code (`CLAUDE.md`), лицензия. Готовое первое сообщение для Claude Code лежит в `docs/first-message.txt`.

## Пять шагов

1. Склонируй репозиторий: `git clone git@github.com:panov-id/pejeded.studio.git`.
2. Открой терминал в корне репозитория и запусти Claude Code командой `claude`. Если Claude Code ещё не установлен, поставь его по официальной инструкции Anthropic.
3. Вставь текст из `docs/first-message.txt` и отправь.
4. Отвечай на вопросы. Claude Code сначала расскажет план, проверит, что есть на машине, и спросит согласие, прежде чем что-то ставить.
5. Когда этап 1 готов, пройди по списку критериев, который он покажет. Потом напиши «начинай этап 2». Первое, что он сделает на этапе 2: измерит скорость картинки на твоей видеокарте.

## Что помнить

- Этапы идут строго по порядку, их тринадцать (раздел 19 задания). Финалов два: ты сыграл настоящий сет и принял программу (этап 10), затем вышла версия 1.0 на GitHub (этап 13).
- Этапы 1–7 делаются без железа, на эмуляторах. MC-707 и DJ-202 понадобятся на этапе 8.
- Хочешь что-то поменять в задании: скажи Claude Code. Он сначала поправит задание, потом код.
