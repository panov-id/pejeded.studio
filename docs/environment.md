Снято 19 ноября 2026 командами `cat /etc/os-release`, `glxinfo -B`, `pw-cli info 0`,
которые выполнил пользователь. Имя пользователя, имя машины и пути из вывода убраны:
репозиторий открытый. Файл дополняется на этапе 1 (раздел 19 задания).

## Что из этого следует

- Образ Docker строится на `debian:13` (trixie), иначе собранная программа может не
  запуститься на машине.
- OpenGL 3.3 core есть с запасом.
- Radeon 610M — встроенная графика начального уровня: по Notebookcheck это графика
  ноутбучных Ryzen и Athlon серии 7020 с двумя вычислительными блоками. Скорость
  картинки — главный риск. Измерение ключом `--bench` — первое дело этапа 2; ступень
  качества по умолчанию и уступки выбираются по нему (раздел 9 задания).
- Процессор, судя по коду видеокарты, из той же ноутбучной серии AMD 7020, запас
  невелик. Видео сначала пробовать кодировать аппаратно (VAAPI), раздел 10 задания.
- PipeWire по умолчанию работает блоком 1024 отсчёта, декам нужен блок 256. Наименьший
  разрешённый блок 32, так что запросить 256 можно; держит ли его машина без щелчков,
  измерить на этапе 1 (раздел 6 задания).
- Частота PipeWire 48 кГц совпадает с частотой DJ-202.

## Что ещё не записано

Снять на этапе 1, ничего не устанавливая на машину без согласия пользователя:

- модель процессора и число ядер (`lscpu`), объём памяти (`free -h`), модель ноутбука;
- тип сеанса, X11 или Wayland (`echo $XDG_SESSION_TYPE`);
- есть ли `ffmpeg` и какие в нём кодировщики (`ffmpeg -version`, `ffmpeg -encoders`);
- есть ли аппаратное кодирование видео (`vainfo`);
- есть ли слой JACK у PipeWire (`pw-jack`), выбранный способ работы со звуком и
  измеренная задержка;
- список пакетов, которые нужны программе на самой машине;
- результаты `--bench` на всех ступенях качества;
- для MC-707 и DJ-202: режим USB Driver, число и порядок каналов, MIDI-порты
  (скрипты `tools/hw-probe`, раздел 20 задания).
