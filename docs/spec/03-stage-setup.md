# 3. Сцена: устройства и маршрут звука

> Часть задания PEJEDED STUDIO, версия 2. Оглавление и список «что читать на каком этапе»: [README.md](README.md). Ссылка «раздел N» в тексте ведёт в файл с номером N.

Приложение играет деки через звуковую карту DJ-202, а грув MC-707 идёт в зал напрямую. В ноутбук по USB возвращается копия всех каналов MC-707: из неё строится куб и пишется запись.

```text
 ноутбук <==USB: звук дек, MIDI==> DJ-202 --кабель: звук + MIDI--> MC-707 --кабель: звук--> пульт, зал
 (деки, куб, запись)                (ручки по MIDI,                 (грув + вход дек,
     ^                               выходы Master, Phones)          общий микс)
     |                                                                  |
     +------------- USB: все каналы MC-707, включая вход дек -----------+
```

- Выход Master контроллера идёт кабелем во вход EXT IN MC-707. Наушники включены в выход Phones контроллера, микрофон — в его MIC IN.
- MC-707 сводит свои треки и деки и отдаёт микс в пульт. Куб питается только каналами MC-707, поэтому деки видны в нём одним источником, как вход 707.
- Темп задаёт ведущая дека, и приложение передаёт его в MC-707 одним из двух основных путей (есть и запасной, через другой MIDI-порт), который выбирается переключателем: напрямую по USB-кабелю MC-707 или через DJ-202, который ведёт MC-707 по MIDI-кабелю (MIDI OUT → MIDI IN). Двигаете питч деки — грув MC-707 ускоряется вместе с треком.
- Если ноутбук зависнет, пропадут деки и картинка, а грув MC-707 продолжит играть в зал.

**Что из этого следует:**

- 20 входов MC-707 сходятся с составом потоков: микс, 8 стереотреков и вход дают 10 стереопар. Порядок каналов (1–2 микс, 3–18 треки, 19–20 вход) — догадка по подписям блок-схемы.
- На MC-707 включить MIDI Sync Out USB, задать Direct USB Mixout и выбрать MIDI Sync под путь темпа: USB для прямого пути, MIDI для пути через DJ-202; годится ли AUTO для обоих, проверить на железе (раздел 20). Режим USB Driver оставить тем, при котором Linux видит много каналов, и записать, какой это режим.
- На DJ-202 для Linux нужен USB mode Generic: драйвера Roland под Linux нет. Это вывод разработчика, в руководстве про Linux ничего нет; проверить (раздел 20).
- Путь темпа через DJ-202 стал конкретнее: известно сообщение, с которого начинать на этом пути (раздел 12). Работает ли оно на DJ-202 и идёт ли после него clock на MIDI OUT, покажет только железо. Найден и второй путь: MC-707 принимает MIDI clock по своему USB-кабелю (раздел 12); пользователь решил 19 ноября держать оба пути с переключателем.
- По словам пользователя (19 ноября), на его машине с Debian с каналами MC-707 уже работали, и система видит и MC-707, и DJ-202. Какой при этом стоял режим USB Driver, сколько каналов видно и в каком порядке, не записано: это снимают скрипты `tools/hw-probe`, когда устройства подключены.
