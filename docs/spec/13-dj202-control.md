# 13. DJ-202: управление и назначаемые действия

> Часть задания PEJEDED STUDIO, версия 2. Оглавление и список «что читать на каком этапе»: [README.md](README.md). Ссылка «раздел N» в тексте ведёт в файл с номером N.

MIDI-коды контроллера лежат в `resources/mappings/dj202.json`, в коде их нет. Начальные значения взяты из открытого маппинга для Mixxx; у каждой записи есть поле `verified`, которое становится `true` только после проверки на настоящем контроллере. Для проверки в Settings есть окно MIDI Monitor, показывающее входящие сообщения.

**Откуда коды и насколько им можно верить.** В основном дереве Mixxx разработчик маппинга DJ-202 не нашёл. Коды взяты из репозитория сообщества mrtnGLSR/DJ-202 (смесь старого маппинга DJ-202 и штатного маппинга DJ-505, для Mixxx 2.5.3). Разработчик прочитал его исходники, но на контроллере ничего не проверял: все коды ниже — отправная точка для этапа 8.

**Запуск связи.** После открытия портов приложение шлёт два служебных сообщения (раздел 12): запрос текущего положения ручек и перевод пэдов под управление программы. Контроллер в ответ присылает положение всех ручек и фейдеров; приложение принимает их как истину для дек в фокусе. В программном режиме всю подсветку ведёт программа. В DJ-505 сообщение поддержания связи нужно, чтобы работала подсветка пэдов; нужно ли оно DJ-202, неизвестно. В файле маппинга оно есть и включается флажком.

**Коды из открытого маппинга** (deck = 0..3 для дек 1–4; сообщения дек 3 и 4 приходят на своих MIDI-каналах: слой переключает сам контроллер):

| Группа | Статус | Коды |
| --- | --- | --- |
| Кнопки деки | 0x90 + deck | 0x00 PLAY, 0x01 CUE, 0x02 SYNC, 0x03 SHIFT+SYNC, 0x04 SHIFT+PLAY, 0x05 SHIFT+CUE, 0x06 касание джога, 0x07 SLIP, 0x08 выбор деки, 0x0D KEY LOCK, 0x0E SHIFT+KEY LOCK, 0x0F VINYL, 0x12 TAP, 0x1B CUE канала |
| Ручки и фейдеры деки | 0xB0 + deck | 0x06 вращение джога (относительное, значение минус 64); питч 0x09 и 0x3B (старшая и младшая части); TRIM 0x16 и 0x34; HI 0x17 и 0x35; MID 0x18 и 0x36; LOW 0x19 и 0x37; FILTER 0x1A; фейдер канала 0x1C и 0x3A |
| Пэды | 0x94 + deck | 0x00 режим пэдов; 0x01–0x08 пэды в режиме HOT CUE (с SHIFT 0x09–0x10); 0x11–0x18 в режиме LOOP; 0x21–0x28 в режиме SAMPLER (с SHIFT 0x29–0x30); 0x41–0x4E кнопки PARAM |
| Общие кнопки | 0x9F | 0x00 SHIFT; 0x02 и 0x03 LOAD слева и справа (варианты 0x04, 0x05, 0x12–0x15); 0x06 и 0x07 нажатие энкодера; 0x1D CUE сэмплера; 0x53 и 0x55 синхронизация секвенсора |
| Общие ручки | 0xBF | 0x00 и 0x01 вращение энкодера; кроссфейдер 0x08 и 0x58; 0x1A уровень сэмплера |
| Эффекты | 0x98, 0x99, 0xB8, 0xB9 | Кнопки и ручки секций эффектов |
| Темп секвенсора | 0xEA | Раздел 12 |

Ручки MASTER LEVEL, PHONES LEVEL и MIXING в маппинге не встречаются, сообщений для индикатора уровня тоже нет (разделы 6 и 11).

**Эскиз файла маппинга:**

```json
{
  "device": "DJ-202",
  "init": [ "F0 00 20 7F 00 F7", "F0 00 20 7F 01 F7" ],
  "keepAlive": { "message": "BF 64 00", "everyMs": 500, "enabled": false },
  "controls": [
    { "id": "play",    "type": "note",     "status": "0x90+deck", "data1": "0x00", "verified": false },
    { "id": "pitch",   "type": "cc14",     "status": "0xB0+deck", "msb": "0x09", "lsb": "0x3B", "verified": false },
    { "id": "jogTurn", "type": "relative", "status": "0xB0+deck", "data1": "0x06", "center": 64, "verified": false }
  ],
  "leds": [
    { "id": "play", "status": "0x90+deck", "data1": "0x00", "on": 127, "off": 0, "verified": false }
  ]
}
```

**Элементы контроллера и их действия:**

| Элемент | Действие | С SHIFT |
| --- | --- | --- |
| PLAY/PAUSE | Пуск и пауза деки в фокусе |  |
| CUE | Поведение cue из раздела 11 |  |
| SYNC | Включить или выключить подгонку | Сделать деку ведущей |
| DECK | Сменить деку стороны (1↔3, 2↔4). Слой переключает контроллер; приложение узнаёт о смене по сообщению выбора деки и по каналу приходящих сообщений |  |
| Питч-фейдер | Темп ±8 % |  |
| KEY LOCK | Включить или выключить keylock (кнопка на DJ-202 есть, по руководству) | Не используется: диапазон темпа в приложении один |
| Джог | Подтяжка при игре, перемотка на паузе. Число шагов на оборот неизвестно, подбирается на железе | Быстрая перемотка |
| Пэды 1–4 (режим HOT CUE) | Hot cue 1–4: поставить или прыгнуть | Удалить метку |
| Пэды 5–8 (режим HOT CUE) | Петля 1, 2, 4, 8 долей |  |
| Пэды в режимах LOOP, SAMPLER, SEQUENCER | Деками не используются; свободны для назначения. При запуске приложение пробует включить режим HOT CUE; можно ли задать режим с компьютера, проверить |  |
| TRIM, HI, MID, LOW, FILTER | Ручки канала деки в фокусе, с мягким подхватом |  |
| Фейдер канала, кроссфейдер | Громкость и смешивание сторон |  |
| CUE канала | Канал в наушники |  |
| MIXING, PHONES LEVEL, MASTER LEVEL | Работают внутри контроллера, приложение их не видит (вывод из маппинга, проверить) |  |
| Энкодер выбора | Движение по списку треков | Пролистывание страницами |
| LOAD (левая, правая) | Загрузить выделенный трек в деку стороны, с защитой |  |
| Секция драм-машины, кнопки эффектов, SLIP, VINYL, TAP | Не используются; свободны для назначения |  |

**Подсветка**, которую шлёт приложение: PLAY (играет, мигает в конце трека), CUE, SYNC (горит при подгонке, медленно мигает у ведущей деки), DECK, KEY LOCK, CUE канала, пэды (метка поставлена, петля активна), LOAD (мигает при отказе). При выходе приложение гасит всю подсветку, которую зажгло.

**Назначаемые действия.** Любое действие из списка ниже привязывается к клавише ноутбука или к любому MIDI-сообщению: в Settings нажать Assign у действия, затем нужную клавишу или кнопку. Привязки хранятся в настройках. Если кнопка уже занята декой или другим действием, показывается предупреждение и запрашивается подтверждение.

| Группа | Действия |
| --- | --- |
| Куб | Плоские карты показать или спрятать; ориентиры показать или спрятать; следующая палитра; надпись включить или выключить; ступень качества; стоп-кадр; снимок; подсказка под курсором включить или выключить; соло следующего и предыдущего источника; снять соло |
| Камера | Пролёт включить или выключить; каждый из четырёх модуляторов; длина фразы 4, 8, 16 тактов; сброс вида; Decay больше и меньше |
| Экраны | Нижняя панель Decks открыть или закрыть; панели Sources и Look; спрятать всё; окно зрителей включить или выключить; Help; консоль; вкладки нижней панели; полный экран |
| Запись | Взвести аудио; взвести видео; стоп |
| Отметки и пресеты | Отметка момента (раздел 10); вызвать пресет вида и камеры 1–8 (раздел 9) |
| Темп и звук | Tap; Monitor включить или выключить; keylock деки в фокусе; следующий путь темпа по кругу (MC-707 USB, DJ-202, Other MIDI port) |
