# 8. Куб: что на экране

> Часть задания PEJEDED STUDIO, версия 2. Оглавление и список «что читать на каком этапе»: [README.md](README.md). Ссылка «раздел N» в тексте ведёт в файл с номером N.

Экран в реальном времени показывает, где сейчас какой звук: каждый звук виден объёмной формой на своём месте в кубе, а форма заполнена нитями из его же сигнала. Это рабочий инструмент: по картинке пользователь пишет музыку и собирает панорамный звук, поэтому точность и читаемость важнее украшений.

Сцена каждый кадр рисуется один раз во внеэкранный буфер («программный кадр») в разрешении записи. Этот кадр уходит в три места: окно зрителей, запись видео и окно ноутбука. Панели интерфейса, плоские карты и подсказка под курсором рисуются поверх только в окне ноутбука.

**Правила картинки** (подтверждены пользователем на прототипе):

- Пространство звука — куб, а не сфера. Оси прямые: влево-вправо — панорама, вверх-вниз — частота, ближе-дальше — сухой или размытый звук. Слушатель в центре, камера внутри.
- Звук виден не точкой, а объёмной формой такого размера, сколько он занимает по панораме и по частотам. Форма по высоте — это АЧХ звука: она занимает те частоты, которые в нём есть, и плотнее там, где частота громче. Ширина формы — фаза: широкий стереозвук шире.
- Форма заполнена пучком нитей, и каждая нить — настоящий сигнал своей полосы частот. Случайного и придуманного узора в картинке нет (требование пользователя): один и тот же звук всегда даёт одну и ту же картинку.
- Только настоящее время: звук есть — форма есть, замолчал — форма пропала за время Decay. Разлетающихся волн, следов, шлейфов и эха нет.
- Цвет — источник (дорожка), с подкраской по высоте. Плотность и яркость — громкость. Белый — только спор двух звуков за одно место.
- Фон чёрный. Вид один; переключения видов нет. Картинка чистая: без песка и дымки между нитями.

**Пучок нитей из настоящих сигналов.** Место и размер звука в кубе даёт поле плотности (раздел 7). Внутри форма заполнена прямыми рядами нитей: нити идут вдоль оси X (панорама), ряды стоят по высоте (один на полосу частот) и по глубине (шаг 0,09). Каждую нить отклоняет сигнал её полосы: по высоте — сам сигнал, по глубине — тот же сигнал со сдвигом на четверть периода и разница каналов. Поэтому тон выглядит спиралью, а не волной на листе, шум — ломаной нитью, широкий звук расходится в глубину сильнее моно. Соседние по глубине ряды показывают соседние куски того же сигнала, поэтому они не копии друг друга.

Объём рисуется трассировкой лучей во фрагментном шейдере. Луч пересекает объём сетки (±1,45; ±1,1; ±1,45) и идёт в два уровня: 56 крупных шагов от входа до выхода, и только там, где общий канал плотности в середине шага больше 0,004, крупный шаг делится на 4 мелких (dt — четверть крупного). Начало мелких шагов сдвинуто на долю шага упорядоченным узором по координатам пикселя (interleaved gradient noise), который каждый кадр сдвигается по порядку, по номеру кадра от 0 до 63. Это сглаживание, на форму нитей оно не влияет; случайных чисел в нём нет, и это единственное в кадре, что берётся не из звука и не из постоянных правил раскладки. Толщина нити не бывает меньше того, что луч успевает поймать (w в формуле), а яркость при этом падает во столько же раз: тонкая нить вдали гаснет, а не искрит.

На каждом мелком шаге в точке p, если общий канал плотности больше 0,006, для каждого источника с плотностью density не меньше 0,006:

```text
h   = clamp((p.y + 0.85) / 1.7, 0, 1)          высота = частота: 0 бас, 1 верха
c0  = round(h * 31)                            ближайшая полоса
w   = max(0.0045, dt * 0.55)                   толщина нити, не тоньше шага луча
acc = 0
для полос c = c0 - 1, c0, c0 + 1 (в пределах 0..31), у которых level >= 0.1:
  (x0, z0)    = центр формы этой полосы (раздел 7)
  al          = p.x - x0                       вдоль нити: панорама
  dp          = p.z - z0                       поперёк: глубина
  kr          = round(dp / 0.09)               номер ряда нитей по глубине
  u           = al / 1.2 + 0.5 + kr * 0.29     место в сигнале полосы; за краями 0..1 сигнал зеркально отражается
  (m, sd, q)  = mid, side, quad сигнала полосы в точке u, -1..1, с линейной интерполяцией между отсчётами
  d1          = p.y - y(c) - 0.05 * m                              отклонение по высоте: сам сигнал
  d2          = dp - kr * 0.09 - 0.028 * (0.8 * q + 0.6 * sd)      отклонение по глубине
  acc        += exp(-(d1^2 + d2^2) / w^2) * smoothstep(0.1, 0.3, level)
t   = acc * (0.0045 / w) * 7 * smoothstep(0.02, 0.3, density) * (0.35 + density)

спор двух звуков: m1 и m2 — две наибольшие плотности источников в точке
clash = smoothstep(0.5, 0.9, m2 / (m1 + 0.0001)) * smoothstep(0.04, 0.22, m2)
d     = t * gain * dt * 9 * (1 + 1.2 * clash)

цвет:
tint(c, h) = поворот цвета c на (h - 0.5) * 0.3 радиан вокруг серой оси (1,1,1), обрезка до 0..1,
             затем mix(c * 0.8, mix(c, white, 0.28), h)
c     = mix(tint(цвет источника, h), white, 0.92 * clash)
near  = 0.22 + 0.78 / (1 + dist^2 * 0.7)       dist: расстояние от камеры до точки

color += (1 - a) * c * d * 1.6 * near          по всем источникам в точке
a     += (1 - a) * min(1, сумма d)            луч останавливается, когда a больше 0.97
после цикла: L = max(color.r, color.g, color.b);  color *= (1 - exp(-1.9 * L)) / L

сдвиг мелких шагов: jit = fract( 52.9829189 * fract( dot( пиксель + кадр * (5.588, 3.117), (0.06711056, 0.00583715) ) ) )
мелкий шаг j = 0..3 берётся в точке начало_крупного_шага + dt * (j + jit)
```

**Что в картинке от чего зависит:**

| Что в звуке | Что на экране |
| --- | --- |
| Баланс левого и правого канала в полосе (pan) | Место формы влево-вправо |
| Частота полосы | Высота; вертикальная форма звука — его АЧХ |
| Сухость (dry): резкие атаки и совпадение каналов | Расстояние: сухой близко, размытый далеко |
| Фаза между каналами (corr) | Ширина формы; явная противофаза — форма сзади |
| Громкость полосы (level) | Плотность и яркость нитей, размах их отклонения; тише порога — пусто |
| Резкая атака (onset) | Форма коротко сгущается: плотность умножается на (1 + 1,3 × onset) |
| Сам сигнал полосы | Форма каждой нити: тон — ровная спираль, биения и переливы — меняющаяся, шум — ломаная |
| Разница каналов в полосе (side) | Дополнительное отклонение нити в глубину |
| Два звука в одном месте, почти равные по силе | Нити обоих белеют |
| Звук замолчал | Форма гаснет за время Decay |

От звука не зависят: цвет дорожки (это её номер), постоянные правила раскладки (какая частота на какой высоте, шаг рядов, размах отклонения, сколько сигнала помещается в нить) и ручка Density. Случайных чисел в отображении нет.

Условности, о которых пользователь знает: размах отклонения нити меньше шага между рядами (иначе пришлось бы проверять втрое больше рядов на каждый шаг луча); куски сигнала на соседних рядах через один идут в обратную сторону, чтобы на стыке не было излома; ровная чистая нота стоит неподвижной спиралью, потому что её сигнал не меняется и снимается всегда с одного места периода.

**Два звука в одном месте: спор** (выбор пользователя из четырёх показанных способов). Если две дорожки занимают одно место на одних частотах (например бочка и бас), это правда о миксе, которую нужно показать. Пока один звук заметно сильнее другого, оба рисуются своими нитями и своими цветами, цвета в третий не смешиваются. Там, где второй по силе звук почти равен первому (clash в формуле: начинается при отношении плотностей 0,5, полный при 0,9), нити обоих белеют и горят ярче. Порог поднят с 0,2–0,7 после проверки на настоящем звуке: при прежнем белело почти всё. Белое на экране значит одно: здесь два звука спорят за место, их надо развести по частоте, панораме или времени. Отвергнутые способы: просто рядом без подсказки; громкий гасит тихого; яркость по фазе между дорожками.

**Подкраска по высоте** (просьба пользователя). Цвет дорожки остаётся её цветом, но внизу он глубже и темнее (× 0,8), наверху светлее (на 28 % к белому): по одной дорожке видно, где её низ и где верх. Сдвиг оттенка оставлен едва заметным (±0,15 радиана): при большем сдвиге одна дорожка становилась похожа по цвету на другую. Силу подкраски выбрал разработчик, пользователю показано.

**Глубина для глаза.** Дальние нити темнее ближних (near в формуле), ближние крупнее за счёт перспективы. Цвет после накопления приводится к экрану по самой яркой составляющей (последняя строка формулы), а не по каждой отдельно: насыщенный цвет дорожки не выгорает в белый, белый остаётся только знаком спора.

**Как пришли к этому виду** (чтобы не повторять отвергнутое):

| Вариант | Почему отвергнут |
| --- | --- |
| Точки, частицы, кольца, столбики анализатора, туманности | Не показывают, где какой звук, или некрасивы |
| Нити по готовому узору из шума, который звук только гнёт и двигает | Узор не из звука; на ровном звуке нити стояли |
| Одна нить на полосу с нарисованной синусоидой по громкости | Волны ненастоящие; стопка линий выглядит графиком |
| Одна нить на полосу с настоящим сигналом, дугой вокруг слушателя | Плоско: одна линия объёма не заполняет; тормозило |
| Глубина по фазе, звук завёрнут в сферу | Почти всё в одном слое, объёма нет |

**Эталон — веб-прототип.** Пользователь посмотрел его и принял («ща норм»); исходник лежит в `docs/prototype/sound-space.html`. Числа в формулах взяты из него. Приложение должно выглядеть не хуже; любое изменение вида сначала показывается пользователю, на настоящем звуке, а не на искусственных данных. В прототипе для этого есть автозапуск демо: адрес с `#auto` и необязательными `p=`, `y=` (наклон и поворот взгляда), `cx=`, `cy=`, `cz=` (место камеры).

| Что | В прототипе | В приложении |
| --- | --- | --- |
| Источники | 5 дорожек демо или один файл; число 5 зашито в шейдер | До 12 источников; число источников — параметр шейдера и размер текстур |
| Измерение | С частотой Rate, по таймеру браузера | 60 раз в секунду по счёту отсчётов; Rate задаёт только обновление картинки (раздел 7) |
| Мера шума полосы (grain) | Считается, но в картинке не используется | Не считается и не хранится |
| Клавиши камеры | W A S D, Q, E и стрелки | Стрелки, Page Up, Page Down (раздел 9) |
| Пролёт | Скорость от громкости и тяга к звуку, без ручек | Четыре модулятора с ручками (раздел 9) |
| Подписи | По-русски | По-английски |
| Соло, стоп-кадр, снимок, подсказка, имена | Нет (есть только выключатели дорожек) | Есть, описаны ниже |

Чего разработчик не проверил в прототипе: движение (смотрел только отдельные кадры с настоящего звука демо), скорость на видеокарте пользователя, работу на треках пользователя.

**Ручка Density** (gain в формуле, от 0,2 до 3, по умолчанию 1) делает нити ярче или бледнее.

**Ориентиры** (Guides; включаются и выключаются, по умолчанию включены): каркас куба — квадрат пола и квадрат верха на высоте −0,9 и +0,9 со стороной 2,5 (от −1,25 до 1,25), четыре вертикальных ребра, крест на полу с подписями front, back, left, right; на рёбрах шкалы частот с делениями 50 Hz, 200 Hz, 1 kHz, 5 kHz, 12 kHz. Высота деления для частоты f: y = −0,85 + 1,7 × ln(f / 30) / ln(16000 / 30). В программный кадр для зрителей и записи ориентиры попадают, только если включены.

**Плоские карты** (Maps; открываются по нажатию, по умолчанию спрятаны): Top — панорама против расстояния (перёд вверху, слушатель точкой в центре); Front — панорама против частот. Каждая форма рисуется эллипсом цвета своего источника: полуоси 1,3 σx и 1,3 σz (на карте Front высота эллипса постоянная), непрозрачность min(0,55; level^2,2 × 0,5 × вес), цвета складываются. Карты рисуются поверх кадра только в окне ноутбука; в окно зрителей и в запись не попадают.

**Палитры.** Четыре набора в `resources/palettes.json`: Neon, Mono, Warm, Cold, в каждом 12 цветов (по числу источников). Первые пять цветов Neon — цвета прототипа: `#FF5C29`, `#FFC71F`, `#FA4299`, `#7380FF`, `#1FE69E`. Остальные цвета и три другие палитры подбираются на этапе 2 и показываются пользователю. Правило для любой палитры: цвета различимы между собой и ни один не близок к белому, потому что белый занят спором. Цвет любого источника можно переопределить; переопределения хранятся в настройках.

**Соло источника** (новое, выбор пользователя 19 ноября). У каждого источника в панели Sources есть кнопка Solo. Пока она нажата, в кубе и на плоских картах виден только этот источник. Соло одно: нажатие на другом источнике переносит его, повторное нажатие снимает. На звук, запись звука и выключатели источников соло не влияет и при перезапуске не сохраняется. В строке состояния горит «Solo: имя». Соло действует на программный кадр, то есть его видят и зрители, и видеозапись. Так решил пользователь 19 ноября.

**Стоп-кадр** (новое). Клавиша Space или кнопка Freeze в панели Look останавливает картинку звука: формы и нити замирают такими, какими были в момент нажатия. Камера продолжает двигаться, поэтому замерший звук можно обойти и рассмотреть со всех сторон. Звук, деки и запись звука идут дальше. В строке состояния горит «Frozen». Повторное нажатие возвращает живую картинку. Стоп-кадр тоже действует на программный кадр (решение пользователя 19 ноября).

**Снимок** (новое). Клавиша F12 или кнопка Snapshot в панели Look сохраняет программный кадр в PNG в папку записей: `{date}_{time}_{set}_shot.png`, в разрешении записи, без панелей. Имя файла на три секунды показывается в строке состояния. Файл пишется в рабочем потоке, рендер не ждёт.

**Подсказка под курсором** (новое). Если курсор стоит над кубом дольше 0,15 с и ничего не тащит, рядом с ним появляется подпись: какой звук под курсором. Пример: `Bass · 110 Hz · L 12 · dry 80% · -14 dB`; если в этом месте спор, второй строкой `clash: Kick`. Подсказка видна только в окне ноутбука, включается флажком Inspect в панели Look или клавишей I (по умолчанию включена), работает и на стоп-кадре.

```text
раз в 0,1 с, по копии поля плотности в памяти (той же, что сейчас на экране):
  луч из камеры через пиксель под курсором, 224 равных шага через объём сетки
  точка = первая на луче, где наибольшая плотность источника >= 0.15;
          если такой нет — точка с наибольшей плотностью на луче, если она >= 0.03; иначе подсказки нет
  источник = у кого плотность в этой точке наибольшая
  полоса   = round( clamp((y + 0.85) / 1.7, 0, 1) * 31 );
             если у источника эта полоса тише 0.1 — ближайшая к ней полоса громче 0.1
  в подписи: имя источника · частота самого сильного бина полосы (peakHz) · панорама · сухость · уровень
    панорама: C при |pan| < 0.02, иначе L или R и round(|pan| * 100)
    сухость:  round(dry * 100) %
    уровень:  level * 52 - 58 дБ; при level = 1 пишется "> -6 dB"
  спор в точке (clash >= 0.5 по формуле выше): вторая строка с именем второго по плотности источника
```

**Свои имена дорожек** (новое). Имя источника правится двойным нажатием в панели Sources, до 16 знаков, хранится в профиле устройства и показывается в панели Sources, в подсказке под курсором и в отметке Solo. Пустое имя возвращает имя по умолчанию.
