# 23. Словарь

> Часть задания PEJEDED STUDIO, версия 2. Оглавление и список «что читать на каком этапе»: [README.md](README.md). Ссылка «раздел N» в тексте ведёт в файл с номером N.

Слова, которые в этом документе всегда значат одно и то же.

**Куб и звук:**

| Слово | Что значит |
| --- | --- |
| Куб | Пространство звука на экране: влево-вправо — панорама, вверх-вниз — частота, ближе-дальше — сухость. Слушатель в центре |
| Источник | Одна стереопара (или один канал) USB-устройства: трек MC-707 или его вход. У источника свой цвет и имя |
| Главное устройство | Входное устройство, с которого берутся запись, монитор и темп по звуку; на сцене MC-707 |
| Профиль устройства | Описание устройства в настройках: сколько каналов, какие пары дают источники, какая пара несёт общий микс, имена источников |
| АЧХ | Какие частоты есть в звуке и насколько каждая громкая. В кубе это форма звука по высоте |
| Окно | Кусок звука длиной около 43 мс, который разбирается за один раз |
| Полоса | Одна из 32 полос частот от 30 Гц до 16 кГц; одна полоса — один этаж куба по высоте |
| Бин | Самый мелкий шаг частоты при разборе окна: 23,4 Гц при окне 2048 и 48 кГц. Полоса собрана из нескольких бинов |
| pan | Баланс левого и правого канала в полосе: −1 слева, 0 по центру, +1 справа |
| corr (фаза) | Насколько каналы похожи: +1 одинаковые (узкий звук), 0 независимые (широкий), −1 в противофазе (звук сзади) |
| level | Громкость полосы от 0 до 1: 0 соответствует −58 дБ, 1 соответствует −6 дБ и громче |
| onset | Свежая атака в полосе; гаснет за 0,1 с |
| Сухость (dry) | Оценка от 0 до 1: звук с резкими атаками и одинаковыми каналами сухой и стоит близко, размытый стоит далеко |
| Форма | Объёмный сгусток одной полосы одного источника на своём месте в кубе |
| Нить | Настоящий сигнал полосы, нарисованный линией внутри формы |
| Спор | Два источника занимают одно место почти с равной силой; их нити там белеют |
| Съём (Rate) | Сколько раз в секунду измерение звука переносится в картинку |
| Decay | За какое время форма гаснет после того, как звук замолчал |
| Программный кадр | Кадр с кубом, который рисуется один раз и идёт зрителям, в запись и в окно ноутбука |
| Соло, стоп-кадр, снимок, подсказка | Показать один источник; заморозить картинку звука; сохранить кадр в файл; подпись о звуке под курсором |

**Деки и темп:**

| Слово | Что значит |
| --- | --- |
| Дека | Один проигрыватель трека; их четыре, контроллер управляет двумя сразу |
| Фокус | Дека, которой сейчас управляет сторона контроллера: левая 1 или 3, правая 2 или 4 |
| Слышна в Master | Дека играет, её фейдер открыт и кроссфейдер не уведён от неё до конца |
| Ведущая дека | Дека, которая задаёт темп остальным декам и MC-707 |
| SYNC | Подгонка темпа и долей деки под ведущую |
| Сетка битов | Положения долей трека: темп и место первой доли |
| Keylock | Темп меняется, а тон остаётся прежним |
| Cue, hot cue, петля | Точка возврата; четыре метки для прыжка; повтор куска в 1, 2, 4 или 8 долей |
| Мягкий подхват | Ручка начинает действовать, только пройдя через сохранённое значение деки, чтобы звук не прыгал |
| Предпрослушка | Звук деки в наушниках до того, как её слышит зал |
| MIDI clock | Импульсы темпа между устройствами, 24 на долю |
| Пути U, A1, A2, B | Способы довести темп до MC-707: U — импульсами напрямую по USB-кабелю MC-707; A1 — сообщением темпа в DJ-202; A2 — импульсами в DJ-202; B — импульсами в другой MIDI-порт, например через адаптер. Путь выбирается переключателем Tempo goes via |
| Консоль (Console) | Слой, выезжающий сверху: журнал событий и строка команд программы и системы; виден только на ноутбуке |
| Тест скорости (Speed test) | Около 30 секунд меряет картинку, запись и звук на этой машине и предлагает настройки, при которых не тормозит |
| Маппинг | Файл, в котором записано, какое MIDI-сообщение контроллера что значит |

**Разработка:**

| Слово | Что значит |
| --- | --- |
| Эмулятор | Встроенная замена устройства, чтобы работать и проверять программу без железа |
| Контейнер (Docker) | Отдельная «коробка» с инструментами сборки, чтобы не ставить их на саму машину |
| Модульный тест | Проверка одной части программы отдельно от остальных |
| Сквозной тест | Проверка всей программы целиком на эмуляторах, без экрана |
| Пропуск звукового блока (xrun) | Компьютер не успел отдать звук вовремя; слышен щелчок или провал |
| Ступень качества | Low, Medium или High: насколько подробно рисуется куб |
| База данных | Файл studio.db в домашней папке: метки треков, история сетов, статистика, отметки момента, пресеты (раздел 16) |
| Отпечаток трека | Размер файла и хэш его первого и последнего мегабайта: по нему программа узнаёт трек, даже если файл переименован или перенесён |
| Сет | Одно выступление или сеанс игры: от первого звука до выхода из программы или 10 минут тишины |
| Подробные записи | Посекундная статистика и журнал нажатий в базе данных; только они удаляются при чистке |
| Отметка момента | Запись «здесь что-то было» со временем сета и записи; ставится клавишей N или командой note |
| Пресет | Сохранённый вид куба и положение камеры; восемь ячеек в панели Look |
| Stats | Вкладка нижней панели со статистикой из базы данных, пять страниц |
| Файл сеанса | Файл, в который программа раз в 2 секунды записывает, что играет на деках, чтобы вернуться после сбоя |
| AGPLv3 | Лицензия открытого кода: код можно брать и менять, но изменения тоже должны быть открыты |
