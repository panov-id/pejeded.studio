## Правила

- Если решение меняется, сначала правится файл раздела и журнал решений (раздел 21), потом код.
- В разделе 21 разделено, что решил пользователь и что предложил разработчик: первое без согласия пользователя не меняется.
- Слово «проверить» в тексте отмечает предположение, а не установленный факт (разделы 20 и 22).
- Эталон картинки: `docs/prototype/sound-space.html`. Фактическое окружение машины: `docs/environment.md`.
