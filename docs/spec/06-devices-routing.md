# 6. Устройства и маршрутизация звука

> Часть задания PEJEDED STUDIO, версия 2. Оглавление и список «что читать на каком этапе»: [README.md](README.md). Ссылка «раздел N» в тексте ведёт в файл с номером N.

У приложения два независимых звуковых тракта: приём с USB-устройств (для куба, записи и монитора) и вывод дек. У них разные устройства и разные часы, и смешивать их напрямую нельзя.

```text
 приложение --USB звук--> DJ-202 --Master, кабель--> MC-707 EXT IN
 приложение <--USB MIDI--> DJ-202 --MIDI OUT, кабель--> MC-707 MIDI IN
 наушники <-- DJ-202 Phones          микрофон --> DJ-202 MIC IN
 MC-707 MIX OUT --кабель--> пульт, зал
 MC-707 <--USB--> приложение   (к приложению: все каналы и MIDI clock; к MC-707: темп на прямом пути)
```

**Источники куба: только USB-устройства и эмуляторы.** Отдельного пути «деки → куб» нет: на сцене деки попадают в куб через вход EXT IN MC-707. Без железа (дома, в дороге) во входах выбирается эмулятор MC-707, и всё работает так же: деки приходят в его EXT IN, общий микс эмулятора слышен в выходе приложения, рисуется в кубе и пишется в запись, то есть сет записывается на компьютере целиком (раздел 14; решение пользователя 19 ноября). Звук других программ не захватывается. Так решил пользователь 19 ноября.

**Входы: любое USB-устройство.** Слой устройств не привязан к MC-707. Источником может быть любое многоканальное звуковое устройство, которое видит система: грувбокс, звуковая карта, микшер. Для каждого устройства хранится профиль: имя, число каналов, карта каналов (какие пары образуют источники куба и какая пара, если она есть, несёт общий микс) и имена источников, которые задал пользователь. MC-707 — первый готовый профиль. Для незнакомого устройства профиль создаётся сам: каналы по порядку разбиваются на стереопары, общего микса нет; его можно поправить на экране Settings. Несколько устройств работают одновременно. Всего источников не больше 12.

**Вход MC-707.** Ожидается 20 каналов. Карта каналов хранится в настройках и правится на экране Settings; значения по умолчанию — предположение, проверить на железе.

| Каналы (по умолчанию) | Поток | Как используется |
| --- | --- | --- |
| 1–2 | MIX | Аудиозапись, звук в видео, монитор, определение темпа по бочке. В кубе не рисуется, иначе всё задвоится |
| 3–18 | TRACK 1–8, по стереопаре | 8 источников куба, у каждого свой цвет |
| 19–20 | EXT IN (деки и микрофон) | Девятый источник куба, один цвет |

- Если устройство отдаёт только одну стереопару, куб рисует её как единственный источник (режим «mix only»).
- Одиночный канал можно назначить моно-источником: он стоит по центру панорамы и узкий.
- Частота дискретизации входа берётся с устройства; анализ и запись работают на ней. Ожидается 48 кГц, проверить.
- Настройки на самом MC-707: включить MIDI Sync Out USB; выставить MIDI Sync под выбранный путь темпа и RX Start Stop USB (раздел 12); задать Direct USB Mixout, чтобы уровень микса в USB не зависел от ручки VOLUME; режим USB Driver оставить тем, при котором Linux видит много каналов.

**Источник.** У каждого источника есть цвет (из палитры, по порядку), имя (по умолчанию из профиля: Track 1…8, Ext In; пользователь может задать своё, до 16 знаков), усиление для анализа и выключатель. Имя, усиление и выключатель хранятся в профиле устройства.

**Главное устройство.** Одно входное устройство отмечено главным (Main): с него берутся аудиозапись, звук в видео, монитор и определение темпа. По умолчанию это MC-707. Если у главного устройства нет пары общего микса, запись и монитор берут сумму его источников. Остальные устройства дают только источники куба и в запись не попадают. У каждого устройства свой поток захвата и свои кольцевые буферы; расхождение часов между устройствами для картинки не важно.

**Выходы дек.** Master и Phones назначаются независимо: устройство плюс пара каналов.

- Варианты в списке: DJ-202, динамики ноутбука, гнездо наушников, HDMI, любое другое устройство системы.
- По умолчанию на сцене: DJ-202, каналы 1–2 Master и 3–4 Phones (проверить на железе). DJ-202 работает на 48 кГц.
- Устройство Master задаёт часы DJ-движка. Если Phones назначен на другое устройство, его сигнал идёт через кольцевой буфер с подстройкой скорости (компенсация расхождения часов).
- Смена выхода происходит без перезапуска приложения; на время переключения допускается короткая тишина с плавным входом, без щелчка.
- Список устройств обновляется при подключении и отключении.

**Ручки DJ-202, которые работают внутри контроллера.** В открытом маппинге Mixxx ручки MASTER LEVEL, PHONES LEVEL и MIXING не шлют MIDI. Вывод разработчика: они действуют на звук в самом контроллере. Поэтому приложение отдаёт в каналы 1–2 чистый Master, а в каналы 3–4 чистую шину предпрослушки (только деки с включённым CUE); баланс «предпрослушка — мастер» в наушниках задаёт ручка MIXING контроллера. Проверить на железе (раздел 20). Если окажется, что MIXING на звук с компьютера не действует, приложение смешивает само, и на панели Decks появляется регулятор Cue Mix.

**Настройки на самом DJ-202** (System Settings; вход в них по руководству: держать кнопку LOAD при подключении USB):

| Настройка | Значение | Зачем |
| --- | --- | --- |
| USB mode | Generic | Работа с системным драйвером; драйвера Roland под Linux нет. Вывод разработчика, проверить |
| Demo mode | Off | Чтобы контроллер не запускал демонстрацию подсветки во время сета |
| Master output reference level | Подобрать | Уровень на входе EXT IN MC-707 без перегруза |
| Mic low cut, noise gate, mic effect | По вкусу | Микрофон обрабатывает контроллер, приложение его не трогает |

Контроллер питается от USB и по руководству подключается прямо в порт компьютера, без хаба.

**Монитор.** Переключатель Monitor подмешивает общий микс главного устройства в выход Master приложения. По умолчанию выключен. Путь идёт через кольцевой буфер с подстройкой скорости. При включении показывать предупреждение, если Master назначен на DJ-202: на сценической схеме это замкнёт петлю (микс 707 вернётся в его же вход). Если главное устройство — эмулятор MC-707, его треки слышны в выходе Master всегда, без переключателя Monitor: у эмулятора нет своего выхода в зал. В Master при этом идут только треки эмулятора, без его канала EXT IN, поэтому деки не задваиваются и петля не возникает.

**MIDI-порты.**

| Порт | Направление | Зачем |
| --- | --- | --- |
| DJ-202 | вход | Ручки, кнопки, джоги, пэды |
| DJ-202 | выход | Служебные сообщения запуска, подсветка, темп для пути через DJ-202 |
| MC-707 | вход | MIDI clock как запасной источник темпа для камеры |
| Direct clock out (по умолчанию MIDI-порт MC-707) | выход | Пути U и B: приложение само шлёт MIDI clock в MC-707. Для пути U это MIDI-порт самой MC-707 по её USB-кабелю (в настройках значение null); для пути B выбирается другой порт, например USB-MIDI-адаптер |

**Как открывать устройства в Linux.** Есть два способа, и интерфейсы `IAudioInput` и `IAudioOutput` для них одинаковы. Первый: приложение работает клиентом PipeWire через его JACK-слой, а его порты соединяются с портами устройств; тогда расхождение часов между устройствами выравнивает PipeWire. Второй: приложение открывает устройства напрямую через ALSA и выравнивает часы само, как описано выше. Какой способ основной, решается на этапе 1 по измеренной задержке и устойчивости; результат записывается в `docs/environment.md`.

**Потеря устройства.** Каждое устройство живёт по схеме Absent → Opening → Running → Lost → Opening. В состоянии Lost приложение раз в секунду пробует открыть устройство заново и показывает предупреждение в строке состояния. Потеря входного устройства убирает из куба только его источники. Если потеряно главное устройство, запись не обрывается: в файл идёт тишина до его возврата (раздел 10). Потеря устройства, на которое назначен Master, ставит деки на паузу с сохранением позиций и после возврата ждёт команды пользователя. Потеря только MIDI-связи с контроллером деки не останавливает, управление остаётся с экрана.
