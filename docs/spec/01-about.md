# 1. Об этом документе

> Часть задания PEJEDED STUDIO, версия 2. Оглавление и список «что читать на каком этапе»: [README.md](README.md). Ссылка «раздел N» в тексте ведёт в файл с номером N.

Это единое задание на разработку PEJEDED STUDIO: что делает приложение и как его строить. Оно заменяет два прежних документа, [план продукта](https://claude.ai/artifact/Mmb4Ne6Cf7ifbwHEGiGQSF) и [техзадание версии 1](https://claude.ai/artifact/MAzVfzDg6jyoQcpuvCEaEt); они остаются как архив и больше не обновляются.

- Разделы 2–3 написаны для человека: что строим и как всё соединено на сцене.
- Разделы 4–20 написаны для Claude Code: как строить, по шагам и с числами.
- Разделы 21–24 справочные: кто что решил, что ещё не известно, словарь, источники.

Слово «проверить» отмечает предположение, а не установленный факт. Эталон картинки — [веб-прототип](https://claude.ai/artifact/6xeefNYiP9dH5WB3kfoTTV), который пользователь принял; состав панелей показывают [схемы экранов](https://claude.ai/artifact/VBHBJK1W7YSvaAZXLv2996).

**Что изменилось против версии 1:**

| Тема | Что стало |
| --- | --- |
| Пространство звука | Куб вместо сферы. Расстояние берётся из сухости звука, фаза даёт ширину. Нити — настоящие сигналы полос, без случайного узора. Принято пользователем на прототипе |
| Формула громкости | Приведена к прототипу; в версии 1 числа расходились |
| Куб как инструмент | Добавлены соло источника, стоп-кадр и снимок, подсказка под курсором, свои имена дорожек |
| DJ-часть | Добавлены индикаторы уровня, возврат дек после сбоя, отметка сыгранных треков |
| DJ-202 | Вписаны коды кнопок и ручек, сообщение темпа и настройки контроллера: из открытого маппинга Mixxx и руководства Roland. На железе не проверены |
| Надёжность | Запрет гашения экрана, конец места на диске, потеря проектора, сдвиг звука в видео, отчёт о сбое |
| Пролёт камеры | Маршрут постоянный, как в прототипе, а не случайный |
| Измерение звука | Идёт 60 раз в секунду по счёту отсчётов и не зависит от Rate; в прототипе шло с частотой Rate. Решение разработчика (раздел 7) |
| Лицензия | Код публикуется под AGPLv3. Пользователь подтвердил это 19 ноября (раздел 4) |
| Темп | Добавлен прямой путь: MIDI clock в MC-707 по её USB-кабелю. Оба пути, прямой и через DJ-202, стоят за переключателем (решение пользователя 19 ноября, раздел 12) |
| Ответы 19 ноября | Закрыты вопросы о лицензии, работе без железа, соло и стоп-кадре при зрителях, hot cue на паузе, клавишах и системе старого мака; бас получил второй вариант за переключателем (разделы 21 и 22) |
| Окружение | Известны система и видеокарта машины разработки: Debian 13, встроенная AMD Radeon 610M, PipeWire 1.4.2 (раздел 4). Скорость картинки стала главным риском; риск «Linux не увидит треки MC-707» снят опытом пользователя (раздел 22) |
| Тест скорости и консоль | Добавлены по просьбе пользователя 19 ноября: кнопка Speed test, после которой программа предлагает настройки (раздел 9), и консоль внутри программы с командами программы и системы (раздел 15). Слои выезжают плавно |
| База данных и статистика | Добавлены по просьбе пользователя 19 ноября: база данных внутри программы (раздел 16), вкладка Stats с пятью страницами (раздел 15), отметки момента и отчёт рядом с записью (раздел 10), пресеты вида и камеры (раздел 9). Темп, сетка и метки трека теперь хранятся только в базе; файла рядом с треком больше нет |
| Новые разделы | Скорость и бюджеты (в разделе 9), автотесты (18), журнал решений (21), открытые вопросы и риски (22), словарь (23) |
| Убрано | Мерка «зернистость» (grain), слова «сфера» и «два режима ноутбука», прежние режимы и фоны |
