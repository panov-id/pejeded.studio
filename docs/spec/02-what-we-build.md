# 2. Что строим

> Часть задания PEJEDED STUDIO, версия 2. Оглавление и список «что читать на каком этапе»: [README.md](README.md). Ссылка «раздел N» в тексте ведёт в файл с номером N.

PEJEDED STUDIO — настольное приложение для одного человека с тремя задачами. Оно в реальном времени показывает, где в пространстве находится каждый звук, играет треки на четырёх деках с контроллера Roland DJ-202 и записывает сет в аудио и видео. Сначала работает на Linux (Debian), затем на старом и новом macOS.

Картинка — рабочий инструмент, а не украшение: по ней пользователь пишет музыку и собирает панорамный звук, поэтому точность и читаемость важнее эффектов. Название PEJEDED STUDIO и надпись в кадре зашиты в код. Интерфейс на английском, общение с пользователем на русском; пользователь не программист.

**Принятые решения:**

| Вопрос | Решение |
| --- | --- |
| Где стоит звук | Считается только из звука: панорама — влево-вправо, частота — высота, сухость — расстояние, фаза — ширина. Ручной расстановки нет |
| Картинка | Куб, внутри которого находится зритель. Звук виден объёмной формой, заполненной пучком нитей; каждая нить — настоящий сигнал своей частоты. Чёрный фон, только настоящее время, ничего случайного |
| Источники куба | Только USB-устройства (первое — MC-707) и встроенные эмуляторы; до 12 источников. Деки напрямую и звук других программ не нужны |
| Куб как инструмент | Соло источника, стоп-кадр, снимок в файл, подсказка под курсором, свои имена дорожек |
| DJ-часть | Четыре деки, микшер, предпрослушка, бегущие вейвформы, SYNC по темпу и долям, keylock, hot cue, петли, список треков. Индикаторы уровня, возврат дек после сбоя, отметка сыгранных |
| Темп | Задаёт ведущая дека; приложение передаёт его в MC-707 одним из двух путей на выбор: напрямую по её USB-кабелю или через DJ-202 и MIDI-кабель |
| Звук на сцене | MC-707 отдаёт микс аналогом прямо в пульт; в ноутбук по USB идёт копия для куба и записи |
| Запись | Взводится заранее, стартует сама с первым звуком. Только звук или видео со звуком |
| Показ | Куб на втором экране для зрителей и на ноутбуке |
| Интерфейс | Одно окно: куб всегда на фоне, всё остальное — слои поверх |
| Обслуживание | Тест скорости одной кнопкой: программа сама предлагает настройки, при которых не тормозит. Консоль внутри программы: журнал, команды программы и команды Linux |
| База данных и статистика | Программа ведёт базу данных: метки треков, история сетов, посекундная статистика звука и скорости, журнал событий и нажатий, отметки момента, пресеты вида и камеры. Всё это видно во вкладке Stats. Старые подробные записи программа предлагает удалить, сама ничего не удаляет |
| Разработка | Сборка и автотесты в Docker, запуск на машине. Версию для macOS собирает GitHub. Репозиторий открытый |
| Железо | Проверяется отдельным этапом в конце; до этого всё делается на эмуляторах |

**Границы первой версии:**

| Входит | Не входит |
| --- | --- |
| Приём многоканального звука с любых USB-устройств; первый готовый профиль — MC-707 | Деки напрямую в куб, звук других программ, ручная расстановка источников |
| Куб: живая объёмная карта «где сейчас какой звук», плоские карты, палитры | Другие виды, фоны, разлетающиеся волны, следы и шлейфы |
| Соло, стоп-кадр, снимок, подсказка под курсором, имена дорожек | Показ тональности и нот |
| Камера: ручная и пролёт с привязкой к звуку | Скретч |
| Запись: аудио (общий микс) и видео со звуком | Запись отдельных каналов, вертикальное видео |
| 4 деки, микшер, предпрослушка, keylock, 4 hot cue, петли, индикаторы уровня | Эффекты, сэмплер, драм-машина DJ-202, автовыравнивание громкости |
| Сетка битов, ведущая дека, SYNC по темпу и долям | Обработка микрофона в приложении |
| Передача темпа в MC-707: по её USB, через DJ-202 или через другой MIDI-порт, с переключателем | Библиотека с плейлистами и тегами |
| Список треков папки с поиском, сортировкой и отметкой сыгранных | Предварительный анализ всей папки |
| Возврат дек после сбоя | Перевод интерфейса, смена названия и логотипа |
| База данных, вкладка Stats, отметки момента, пресеты вида и камеры | Импорт библиотек других DJ-программ, автоматическая синхронизация базы между компьютерами |
| Эмуляторы DJ-202 и MC-707, тестовые сигналы | Автообновление, магазины приложений (готовые пакеты .deb и .dmg входят: этап 11) |
| Вывод на второй экран, назначаемые клавиши и кнопки | Windows |
